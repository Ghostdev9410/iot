This module extends the functionality of the ``iot_oca`` module to
support the MQTT protocol. It allows Odoo to act as an MQTT client,
subscribing to topics and publishing messages to MQTT brokers.

Configuration
=============

To configure this module, you need to:

1. Go to **IoT > MQTT Brokers**.
2. Create a new Broker record.
3. Enter the Host (e.g., ``mqtt.example.com`` or IP address).
4. Enter the Port (default ``1883`` or ``8883`` for SSL).
5. (Optional) Set Username and Password.
6. (Optional) Enable SSL/TLS if required.

   - If SSL/TLS is enabled, the connection will use system trusted
     certificates by default.

7. Click **Test Connection** to verify settings.
8. Click **Start Listener** to begin receiving messages.

Usage
=====

To use this module with an IoT Device:

1. Go to **IoT > Devices**.
2. Select or create a Device.
3. In the **MQTT Configuration** tab:

   - Select the **MQTT Broker**.
   - Set the **MQTT Topic** (e.g., ``sensor/temp/01``).
   - Set the **QoS** level.

4. Once the Listener is active on the Broker, any message sent to this
   topic will be logged in the device's **MQTT Messages** tab.
5. You can also send a test message from Odoo to the device using the
   **Publish Test** button.

Known issues / Roadmap
======================

- The listener runs in a separate thread. If Odoo is restarted, the
  listener must be started manually (or an automated cron job could be
  added).
- Currently supports basic authentication and SSL/TLS.
